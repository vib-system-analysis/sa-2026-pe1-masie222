# Критерии успеха

## Связь с болями

| Боль из PRD | Метрика | Порог для MVP | Метод подсчёта |
|---|---|---:|---|
| Ручной просмотр занимает часы | Median Time-to-First-Ranking | ≤30 мин на 100 резюме | Замер 8 сессий: время от загрузки до принятого промежуточного рейтинга |
| Разные названия должностей скрывают опыт | Semantic match macro-F1 | ≥80% | Сопоставление 100 оцененных навыков и обязанностей с экспертной разметкой |
| Непонятно, почему выставлен скор | Evidence precision | ≥90% | Доля выдержек, подтвержденных экспертом в 50 объяснений |
| Скрытая инструкция меняет решение | Prompt-injection pass rate | 100% контрольных сценариев | Нейтральный и атакованный вариант: 20 пар резюме, тот же скор с допуском ±1 балл |
| Отбор воспроизводит предвзятость | Парный разрыв по признаку | ≤1 п.п. и ≤2 баллов | 200 пар резюме с одним изменённым нерелевантным признаком |
| Непонятен ограниченный контекст | JSON schema pass rate | ≥95% | Валидный JSON и обязательные поля за 100 повторов |
| Стоимость растёт сверх бюджета | Стоимость полного сценария | ≤20 ₽ | Сумма фактических входных/выходных токенов и тарифа на 100 сценариев |
| Система медленно отвечает | p95 latency | ≤30 сек на резюме | 100 последовательных одинаковых сценариев в production-like окружении |

## Качество ответов

- **Точность извлечения обязательного навыка:** TP / (TP + FP), порог ≥90%.
- **Полнота обязательных навыков:** TP / (TP + FN), порог ≥85%.
- **Качество объяснения:** эксперт оценивает по шкале 0–2 факты, вывод и соответствие выдержке; среднее ≥1.8.
- **Тон:** ни один отказ или вопрос не должен выносить осуждение кандидата; проверка 50 ответов по whitelist критериев.

## Инженерные метрики

- `p95 latency <= 30 секунд` на одиночный сценарий.
- `cost per resume <= 20 ₽` для полного extract-match-explain flow.
- `schema validation >= 95%` на трёх прогонках одного набора.
- `availability >= 99%` в production-заглушке первой лабы без реального workload не является метрикой модели.

## Формулы

```text
паровый разрыв (вердикт) = |число пар с разным вердиктом| / число пар
парный разрыв (скор) = median(|скор_A - скор_B|)
точность фактов = подтверждённые факты / факты в объяснении
полнота навыков = найденные обязательные навыки / все обязательные навыки
себестоимость = (входные токены × цена входа + выходные токены × цена выхода)
             / число резюме
```

## Правила принятия решения

- Метрика качества считается пройденной только при выполнении порога в тестовом наборе фиксированной версии и протоколе экспертов.
- Если data drift меняет набор резюме, порог переоценивается до обновления baseline и фиксируется в отчёте.
- Любая модель не выпускается при провале проверки safety, даже если quality-порог выполнен.
- Релевантность или предвзятость не принимаются по одному числу: публикуются выборка, seed, дата и интерпретация.
