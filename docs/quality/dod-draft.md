# Черновик Definition of Done для лабораторной 2

## Документы продукта

- [ ] PRD называет один конкретный сегмент, реальные подтверждённые боли с эпизодами и измеримый North Star.
- [ ] PRD содержит границы MVP и ограничения обработки персональных данных.
- [ ] 3–5 гипотез содержат условие опровержения и план проверки.
- [ ] Глоссарий содержит 15–30 терминов, и термины совпадают с PRD, брифом и гипотезами.
- [ ] Бриф читается за ≤2 минуты и содержит изменение мира от боли к результату.

## Технический каркас

- [ ] README описывает назначение, запуск и структуру репозитория.
- [ ] Репозиторий клонируется, а dev-среда запускается одной командой без ручных подмен конфигурации.
- [ ] CI выполняет lint и проверку структуры артефактов на открытом PR.
- [ ] Public hello-world доступен по URL из README.
- [ ] PR-template содержит ссылки на артефакты лабораторной и чек-лист проверки.

## AI и данные

- [ ] Исследование содержит проверенные ссылки и раздел с выбраным подходом.
- [ ] ADR фиксирует прямой промпт, RAG или агента и называет цену решения.
- [ ] Кандидаты моделей сравниваются минимум по стоимости полного сценария и рискам размещения.
- [ ] Ноутбук запускается повторяемо на синтетических примерах.
- [ ] Golden dataset содержит минимум 10 синтетических примеров в документированном JSON-формате.
- [ ] Источник, разрешение, owner и версия сохранены для каждого примера.
- [ ] Prompt-injection и fairness-атакующие наборы включены до выпуска оценки модели.

## Quality & Safety

- [ ] Каждая метрика содержит число, выборку и способ подсчёта.
- [ ] Для каждой боли из PRD назначена метрика и порог продукта.
- [ ] Указаны latency и стоимость полного сценария.
- [ ] Есть formal rule для остановки при провале safety-критерия.
- [ ] Результаты разделены на quality и safety и не смешиваются в одну mean-метрику.

## Приёмка

- [ ] Product / VO и вся команда прочитали PRD вслух.
- [ ] Глоссарий согласован в терминологии всей команды.
- [ ] AI Engineer показал, что показали первые пробы и какой подход выбран.
- [ ] RAG/agent/prompt ADR содержит альтернативы и долг решения.
- [ ] Все ссылки в артефактах проверены вручную перед merge.
- [ ] Диспута приняла артефакты по критериям конкретной выданной роли и секции работы.

## Публичные зависимости

Условие о сдаче на Диспуте не проверено публичным endpoint в этой итерации: адрес https://disputa.ru/app/works/1 перенаправляет на `/login`. Фактические поля приёмки и отзывы преподавателя добавляются после авторизации владельца репозитория.
